## Tips for good screenshots

- **Aspect ratio**: target roughly **4:3 or 16:10** for the cropped image. Each slide reserves ~600×400 px of visual real estate. Anything taller gets letterboxed.
- **Zoom level**: take screenshots at the browser's default zoom (100%) so the font weights match what the audience will see live.
- **Hide your taskbar** before capturing (`F11` in Chrome for fullscreen, then snip).
- **PNG over JPG** for sharp text. Compress with TinyPNG afterward to keep the deck file small if needed.
- **Crop the browser chrome** (URL bar, bookmarks) — the deck already draws a fake browser frame around the image.
- **Use real data**: place a couple of test orders first so the kanban and dashboard look populated, not empty.
